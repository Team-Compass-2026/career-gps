## learning_path

### Data Analyst

Phased plan (10 hours/week, ~6 months): Phase 1 Foundations — SQL (SELECT, JOINs, aggregates) ~6 weeks, Excel fundamentals ~4 weeks. Phase 2 Analysis — Python + pandas ~8 weeks, statistics ~4 weeks. Phase 3 Portfolio — 2–3 analysis projects + dashboard ~4 weeks. Then apply for internship/entry roles.

### Data Scientist

Phased plan: Phase 1 Analytics foundations (SQL, Excel, Python) ~12 weeks. Phase 2 Statistics & ML (probability, regression, scikit-learn) ~12 weeks. Phase 3 Projects & communication (portfolio, case studies) ~8 weeks. Total ~8 months at 10 hours/week. Many start via Data Analyst first.

### Software Engineer

Phased plan: Phase 1 Language + Git (JavaScript/TypeScript) ~8 weeks. Phase 2 Web fundamentals (HTML/CSS/HTTP/APIs) ~8 weeks. Phase 3 Data structures & algorithms + projects ~12 weeks. Phase 4 Portfolio + applications ~8 weeks. Total ~9 months at 10 hours/week.
