## career_description

### Data Analyst

A Data Analyst turns raw data into clear, actionable insight for business decisions. Day-to-day work involves writing SQL queries, building dashboards (Excel, Power BI, Tableau), cleaning data, and presenting findings to non-technical stakeholders. Entry-level roles usually require SQL, Excel, and basic statistics; Python is increasingly expected. Typical employers: banks, retail, healthcare, tech, government. Curated guidance — verify against current local listings.

### Data Scientist

A Data Scientist does deeper work than analysis: building predictive models, designing experiments, and communicating uncertainty. Requires stronger mathematics (linear algebra, probability), Python (pandas, scikit-learn, PyTorch), statistics, and often machine learning fundamentals. Entry into data science commonly flows through a Data Analyst or business-analyst role first. Curated guidance — not a guarantee of outcomes.

### Software Engineer

A Software Engineer designs, builds, and maintains software systems. Core skills: one or more programming languages (JavaScript/TypeScript, Python, Java, Go), data structures and algorithms, version control (Git), and often web fundamentals (HTTP, APIs, databases). Roles range from backend, frontend, to full-stack. Internship-ready usually takes 6–18 months of consistent practice depending on hours available. Curated guidance.
