## faq

Q: Can I switch careers from business admin into data without a CS degree?
A: Yes — many analysts transition from business/finance using SQL + Excel + portfolio projects. Data analyst is a common on-ramp before data science.

Q: How long will it take if I only have 10 hours a week?
A: Plan on roughly 6–9 months to internship-ready depending on target role and starting point. Steady weekly practice beats bursts.

Q: What should I build in my portfolio?
A: 2–3 real analysis projects (clean data → insights → dashboard → write-up) that match the role you want. Quality over quantity.

Q: Should I learn Python or Excel first?
A: For data analyst roles, SQL and Excel first; add Python as you grow. For data science/engineering, Python is essential.
